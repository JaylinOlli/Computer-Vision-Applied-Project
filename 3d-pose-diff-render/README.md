# Computer-Vision-Applied-Project Project title: Improving 3D Human Pose Estimation Using Differentiable Rendering
Track: Differentiable Rendering; Analysis-by-synthesis pose refinement.

### Team: 1 
Members: Elif Bayrak, Ipule Pipi, Jabari Sterling, Jaylin Ollivierre

## Hypothesis: Optimizing MediaPipe's initial pose estimate via differentiable rendering will reduce the error between the estimated and ground-truth 3D poses.

## Dataset: 
3DPW (3D Poses in the Wild) We will use 3DPW as our primary dataset because it contains real-world human images/videos along with SMPL-based 3D human body poses, making it well-suited for evaluating our differentiable-rendering approach. 

## Evaluation plan: 
For our project, we will use MediaPipe Pose as the starting point for human pose estimation. Given an RGB image or video of a person, MediaPipe will detect 33 body landmarks and generate an initial pose estimate. We will then map this initial pose onto the SMPL 3D human body model and use a differentiable renderer, such as PyTorch3D, to render the estimated pose. We will compare the rendered result with the original image and use the difference as a loss function to iteratively refine the pose. 
MediaPipe Pose + Differentiable-Rendering Pose Refinement. We will compare both results against the 3DPW ground-truth poses to determine whether differentiable rendering actually improves the original MediaPipe pose estimate. The key measurement will be the MediaPipe pose error before refinement compared with the MediaPipe + differentiable-rendering error after refinement. We will use the following for our evaluation metrics: MPJPE (Mean Per Joint Position Error), PA-MPJPE (Procrustes-Aligned Mean Per-Joint Position Error), and 3D joint/orientation error.

## Compute: 
The main computation will involve rendering the SMPL model, comparing the rendered image with the original, computing the loss, computing gradients via the differentiable renderer, and iteratively updating the pose parameters.

## Questions (A few ideas of what we could choose from, but we plan to work toward answering the first three): 
Can differentiable rendering improve 3D human pose estimates generated by MediaPipe Pose? 
How much does differentiable rendering reduce the pose error compared with the original MediaPipe estimate? 
How does the quality of the initial MediaPipe pose affect the refinement process? 
How many optimization iterations are needed to achieve meaningful improvement? 
Does the refined pose consistently outperform the original MediaPipe pose? 
What loss function produces the best pose refinement? 
Application: Can we use differentiable rendering to estimate an athlete’s 3D running, jumping, or lifting mechanics from ordinary video or photos, and refine the pose to improve biomechanical analysis?
